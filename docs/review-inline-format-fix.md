# 行内定位格式兼容修复

版本：manager-review-inline-20261015-r2，基于已发布的 inline r1。

用户报告总评中有 P1 和定位编号，但发布统计为零。用户提供的是格式摘要，未提供完整原始报告，不能据此验证 R1245、R760 是否属于当次快照。已在冻结的 r1 镜像中复现独立缺陷：同样有有效编号和正文的 `p1 标题 定位R2` 被解析为空；r1 只接受固定三级标题及紧邻的全角冒号定位行。

## 范围与实现

人工基线是从总报告找到问题，再查找 PR 对应行并手工复制意见。目标用户为现有 AI Review 使用者；输入仍为固定 PR diff 和编号索引。只在既有解析器中兼容标题层级、大小写、列表、加粗、代码标记，以及定位字段的空格、冒号和同一行写法，不增加模型调用、工具或工程读取。

位置必须是快照中唯一存在的 R 编号；不存在的编号、多位置范围、冲突字段、代码块示例、引用内容、待确认章节和未完整结束的输出不发布为独立评论。发布前后继续核对固定版本、路径、新旧侧、行号和补丁原文。

新任务显示新增评论、历史重复和本地位置校验未通过的数量；提取不到位置时明确说明，不能把零条行内评论等同于没有缺陷。旧任务冻结的正文继续沿用 r1 文案，保证升级后恢复发布时仍可逐字回读核对。旧报告不会自动补发，升级后新建审查生效。
