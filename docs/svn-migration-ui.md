# SVN 页面与预检历史交付记录

本次接续“规划 SVN 多实例迁移功能”最后中断的页面实现，范围是已确认的迁移工作台、左来源右仓库的选择页、共用预检详情与独立执行详情。历史转换、内容验证和原迁移边界沿用已验收的 r9。

## 完成内容

工作台按计划展示状态、当前预检和待办；来源页分别展示迁移事实与最近相关预检，跨来源保留勾选。两处通过同一预检编号进入详情，修改来源、仓库、目标或计划后不再把旧结果作为当前依据。重新预检生成新记录，旧记录可以前后翻阅；升级只回填仍存在的旧版最后一份预览。

执行详情保存独立地址，刷新恢复同一任务；计划名称和关联预检来自执行快照，队列保持真实顺序，不因来源分组而重排。只展示实际阶段及可测的提交核验量。提交回执丢失后，在同一确认窗口重试沿用幂等标识。

沿用已有 Vue、Element Plus、权限、CSRF、SQLite 启动锁与独立 Worker，没有增加运行依赖。图标与操作通过弹性布局和网格布局排列。

## 验证与证据

- 迁移单元回归 30 项通过，其中新增 5 项覆盖历史持久化、同一记录关联、输入过期、全局失败、升级回填、历史导航、迁移事实与失败分离及不可变执行摘要。
- 升级控制器 12 项、认证与备份快照 27 项通过。首轮备份测试因只读源码挂载下的默认诊断目录不可写而失败；保留原日志，将测试诊断目录指定到容器临时目录后通过，未修改断言。
- 生产构建的浏览器交互 13 项通过，覆盖工作台、跨来源勾选、共用详情、历史翻阅返回路径、回执丢失重试、执行详情刷新和四页面窄屏布局。该部分使用模拟接口，不算作真实内容迁移证据。
- 三个真实隔离 SVN 与增强版 Gitea 的 44 项集成检查通过，包含首批 9 仓库、后续追加、逐提交内容核验、私有访问、强杀恢复、历史外部引用与重名阻断。
- 真实浏览器另验证登录、导航、来源与仓库登记、预检、停写确认、执行成功、预检历史和来源页迁移结果。精确结果见 `work/svn-acceptance/gm-svn-ui-20261022-r10/live-ui-r10.json`。
- 对照四张选定设计图检查了实际浏览器截图；修复了页面切换保留旧滚动位置、正文层级偏小与工作台密度偏低的问题。图像、区域对照与结论见项目根目录 `design-qa.md`。

开发证据位于 `work/svn-ui-implementation-r1/` 和 `work/svn-acceptance/gm-svn-ui-20261022-r10/`。后者含隔离凭据，禁止打入交付包。正式包继承 r9 固定源码，只叠加本次 SVN 页面及预检记录相关变更，避免引入其他会话正在开发的后端功能。

## 离线包验收

首次安装包通过原安装入口，固定 Linux amd64 镜像、SVN Worker 与核心服务正常。原 r9 隔离安装实例通过原升级入口，SVN 来源、计划、加密凭据、迁移密钥和原登录会话保持一致。两个实际归档均核对路径、全部清单文件和 SHA-256；未包含运行数据库、密钥、工作区或开发缓存。精确身份与不含凭据的结论见 `docs/evidence/svn-migration-ui-release.json`。
