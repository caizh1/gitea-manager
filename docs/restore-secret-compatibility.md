# 已有 Gitea 的恢复密钥兼容修复与验收

日期：2026-10-13。只在独立标记实例验收，未连接或修改用户现有 Gitea。

## 原因与变更

原恢复代码要求目标容器必须设置固定的 `GITEA__security__SECRET_KEY_URI`，否则在解压后拒绝恢复。它将一键安装包的部署约定误当作恢复前提，普通 Compose 实例因此无法恢复。

现在使用备份中实际的源密钥恢复数据，同时保留目标 `app.ini` 中的数据库连接、域名和其他配置。明文密钥、数据目录内的文件密钥、外置文件密钥及 `__FILE` 注入均纳入处理。未显式配置密钥的历史官方实例使用其原有兼容值，不生成新密钥代替。

新备份附带与原配置摘要绑定的 `manager-secrets.json`，使源实例的外置密钥也随备份保存。旧普通 dump 可直接使用其中的 `app.ini` 或数据目录密钥；旧备份若未包含外置密钥，必须重新备份源实例，不能猜测或使用目标密钥代替。备份本身含敏感数据，应与原完整备份一样限制访问。

目标有环境覆盖时，按原实际镜像、挂载、网络、固定端口及其他容器配置建立替换容器；原容器在验证完成前保留。自动同步 Compose 最后一个配置文件中该服务的密钥环境项，使后续 Compose 重建仍使用恢复后的源密钥。外部 Secret 文件和 `.env` 不修改。Compose 文件保留权限和属主，并以原内容摘要检查并发修改；共享 YAML 锚点不得使其他服务同时被修改。

启动就绪后回读实际配置和密钥，确认没有被入口脚本覆盖，再执行原有健康及 Commit 校验。校验失败时一起恢复数据库、仓库、配置、原容器和 Compose 文件。辅助容器与替换容器使用原容器实际镜像 ID，避免镜像标签变化导致使用另一版本处理数据。密钥通过文件归档接口读取，不写入命令输出或诊断记录。

## 支持边界

- 验收平台为官方 Gitea 1.26.4、PostgreSQL 17.11、Linux amd64、持久 `/data` 卷和普通 Compose 配置；同机 Docker 与受信 SSH 共用恢复实现。不是目标现场主机的部署验收。
- 目标必须使用固定宿主端口或不发布宿主端口。Docker 随机端口在原容器停止、启动后也会变化，现于停机前明确拒绝；可将当前端口固定到 Compose，无需重装。
- Compose 文件需在原宿主机存在且可写。自定义 YAML 标签、仅通过 `include` 引入而无法确定服务写入位置、自动删除容器及共享其他容器网络等无法安全处理的配置，会明确拒绝。密钥中的 INI 递归引用或首尾有效空白也会拒绝，避免无声改变密钥。
- 恢复期间不要同时由其他控制器重建目标或编辑其 Compose。摘要冲突不会覆盖他人变更。断电、进程强杀或回退本身失败会保留恢复锁、原容器/数据回退点以及 Compose 备份，需据诊断处理，不盲目重放恢复。
- 此次没有改造 Gitea 源码、数据库结构或加密字段，也没有通过重新加密若干已知字段来替代正确迁移原密钥。

## 验收基线与指标

目标用户是管理已有 Gitea 的运维人员。人工基线包括确认源密钥、判断环境变量覆盖、改目标配置及 Compose、保存回退点、恢复、重启、核对 Git 和加密数据、失败时回退。

固定样本为独立 Compose 创建的目标、真实源实例、真实私有仓库以及四个带加密两步验证种子的用户。两步验证通过真实 Gitea API 校验动态验证码，而非仅比较数据库文本；同时检查 Commit、私有 Git 协议、实际端口、挂载及外置文件。失败样本破坏备份 Commit 摘要，使真实恢复完成后进入验证失败分支，再验证原账号与原仓库。

质量门槛：所测场景成功误报为零、源密钥一致、重启和 Compose 重建保持、失败回退保持原数据、日志不含明文密钥。完整矩阵六个场景终态符合预期，包含五个成功场景和一个主动制造的失败场景。人工精力减少 80% 是目标，本轮没有人工流程对照计时或计数，不宣称已量化达到。

## 首次失败与处理

- Docker 默认地址池耗尽：为独立验收网络指定已确认空闲的子网，不清理其他项目网络。
- 测试样本缺少必填字段、未注册新增权限表：修正隔离初始化，原始失败日志保留。
- Docker 返回的挂载数组顺序不稳定：按挂载内容排序比较，仍严格核对类型、来源、目的地与读写权限。
- 随机端口回退后变化：确认属于 Docker 停止、启动语义，增加停机前拒绝，并以项目正常固定端口配置验收；不删除端口一致性断言。
- 最终镜像复验准备账号时曾发生 Docker CLI 执行 60 秒超时，未进入该次恢复。无法从已清理的临时进程确认其更深层原因；保留原失败，改用 Gitea 管理 API 建立用户样本，不增加超时、不放宽恢复断言。
