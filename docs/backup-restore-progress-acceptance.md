进度和步骤持久化到 SQLite，连续计量最多每秒提交一次，阶段切换和最终数量立即保存。使用现有脱敏机制。进度写入会话故障不回滚已保存的业务终态。页面按任务 ID 展示所有返回任务；活动时每 2 秒、空闲或后台每 10 秒只读刷新，请求超时 8 秒，串行且卸载取消。网络失败保留上次记录。服务器详情轮询只读任务接口，不反复执行 Docker/SSH 探测。

## 首次失败及处理

验收脚本最初使用 Docker 已不提供的顶层 IPAddress，改为从 bridge 网络读取。SQL 回退首次 Git 探测早于服务启动就绪，增加真实健康等待后访问通过。双 Worker 脚本首次模块路径误用冒号，Gunicorn 要求逗号，保留失败日志后单独修正验证。页面发现保存回退点被回退关键字误判为失败，改为精确匹配 rollback 并增加回归测试；验证末尾补充最终仓库计数，避免节流留下不足总数的旧计量。
