# Code Review 自动发布

启用仓库后，PR 创建和更新会触发审查。完整审查结果通过证据、版本和权限校验后，由后台自动发布行内评论和固定总览。

模型与设置继续控制模型、思考档位和预算。任务详情显示分析结论、写入进度、成功评论数和自动重试时间。旧发布确认接口返回 410，刷新页面即可使用当前版本。

可定位意见进入行内评论。无法定位和过长意见进入总览摘要，完整正文保存在任务详情。问题修复和复发沿用原编号。人工编辑的讨论保留，最新复审状态进入固定总览；原总览被编辑或删除时，后台建立新的受管理总览。

每个任务先保存固定发布计划，再发送写请求。写入响应丢失时持续读取回执，发现原评论后自动继续。尚未发送的操作会在恢复后执行。超过 30 分钟的未决回执产生单任务去重告警，后台继续核对。新版本仍可分析，同一问题和总览的写入按回执顺序处理。

升级后，旧待发布任务自动进入队列，重新检查权限和提交版本。过期任务转向当前版本。旧已发布记录和确认审计保留。

模型能否识别具体缺陷仍取决于实测。本次发布机制以真实 Gitea 的自动写入、去重、状态复核及异常恢复作为工程验收条件。
