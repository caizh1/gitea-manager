## 确定性定位、版本与恢复

真实 Git、Webhook、Worker、Linux OpenCode 与 Gitea 配合本机协议替身，完成 29 项边界/异常检查，以及 1 项真实 PR 的重复事件检查。协议替身仅验证工程行为，不作为真实模型质量结论。

新增、修改、删除行、删除文件、重命名与中文空格路径、多个 hunk、重复函数片段、CRLF、末尾无换行均按预期位置发布；函数内重复原文、错误锚点、错误引用、无法定位均降级普通意见。这批固定定位样本错误行内评论为 0，预期降级全部通过；该数值不是所有实际代码的定位保证。

模型执行期间 Push 只发布最新 SHA；发布前版本变化阻止旧结果。真实 Worker 强制停止后，原任务通过租约恢复，没有重复 Review。追加提交重新计算行号并引用历史问题；rebase、force-push、人工重审、多 Commit 累计差异和部分覆盖标识均通过。同一真实 PR 重复投递 20 次签名事件，没有增加任务或 Review。

发布驱动另执行 7 类检查：正常一次 COMMENT、取 diff 时更新版本、发布前更新版本、真实成功响应丢失、残留 PENDING、权限拒绝、租约失效。正常与响应丢失路径均只有一个正式 Review；不删除开发者讨论。最终校验器还补充核对了总结正文与本地冻结结果完全一致。

部分写入通过测试控制器在真实 Gitea 创建 PENDING 后注入响应丢失，不声称复现了某个原生服务端异常。首轮权限拒绝为网关注入；随后已追加真实撤销测试仓库机器人权限的 Gitea 拒绝测试，正常、响应丢失及真实拒绝三项均通过。相关 JSON 位于 `AIReview直接发布证据/真实发布竞争-*.json`。
