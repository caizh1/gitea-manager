# GitLab／Gitea 迁移真实环境试用包

本包来自当前迁移候选，接收协议为八。配套镜像为 `gitea-migration-receiver:offline`，具体接收端提交、二进制摘要和源码包摘要以 `offline/git-migration-receiver.json` 为准；Manager 及全部镜像身份以 `docs/git-migration-build.json` 和 `offline/镜像清单.json` 为准。

## 本次修复

结束预迁移时，数据库读取失败会返回失败并保留现场，恢复后可重试。只有确认尚未创建接收会话时，才执行创建前收尾；等待期间出现的新协议会话不会被旧逻辑接管。返回“已终止”前，还会核验所有原生制品回执已经完成回收。

已经存在的异常旧现场保持原状，不自动补录回执、重建发布基线或强制解锁。出现无法确认的状态时继续保留隔离。

## 试用方式

在独立试用实例解压包。Manager 首次安装使用包内 `install.sh`，已有独立试用 Manager 按 `upgrade.sh` 的引导升级；安装前提和环境选项沿用包内 README。接收端须使用本包配套镜像，并在 Manager 连接检查中确认协议八能力。

先选少量有代表性的真实项目，迁入专用目标群组。按页面完成来源登记、盘点、人员映射、预迁移、平台行为差异确认和正式启动。来源保持停写并保留原数据，验收完成后再切换日常使用。

验收时核对仓库与分支、成员权限、议题／PR、讨论历史和制品下载；另用可丢弃的试用批次验证中断后继续及“重试结束预迁移”。结束成功应同时满足原生制品已回收、来源附件仍可核验和 Manager 实例占用释放。

## 验证边界

本次执行 SQLite 与 PostgreSQL 16.8 的定向服务回归，并使用包内镜像进行真实 HTTP 发布、丢失终止响应后的恢复和重复终止冒烟。详细本轮结果随交付说明提供。

此前的 GitLab／Gitea 固定基准、权限和完整性验证继续作为已有证据；本次没有重复全部历史矩阵。试用包不表示已完成生产部署、任意版本／规模、长期负载或人工节省比例验证。
