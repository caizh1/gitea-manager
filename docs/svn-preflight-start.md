# 预检通过后直接开始 SVN 迁移

此前预检通过后，管理员还需返回迁移工作台、寻找对应计划，再点击“检查并执行”。现在有效的最新预检详情页直接提供“开始迁移”：打开既有目标与范围预览，确认完整读取权限和来源备份停写后，提交同一计划并自动进入执行进度页。

旧预检提供最新结果入口；已有同次预检任务时提供进度或结果入口。开始前重新读取计划及任务，避免沿用已更新的预检或重复引导创建任务。页面切换后到达的响应不会在其他页面打开确认窗口。后端的预览摘要、输入有效性、停写确认、互斥和幂等校验保持不变。

目标用户为平台管理员，输入为已经完成的 SVN 预检记录。人工基线包含返回工作台及定位计划后的两步额外操作；本次验收要求预检页内完成确认并进入任务，额外页面跳转为零。未实测真实用户耗时和整体人工介入比例，不宣称减少人工 80%。

- 前端生产构建及 30 项既有 SVN 迁移回归通过。
