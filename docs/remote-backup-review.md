### RB-CONFIG-001：恢复成功后丢失源的全局登录要求

- 严重级别：P1。
- 位置：`backend/services/local_restore.py:172`。远程模式通过 SSH Docker API 进入该恢复器；函数名不能作为仅限本机的反证。`backend/services/restore_secrets.py` 只同步密钥覆盖，不合并一般业务配置。

- 实际影响：原来必须登录才能获取的仓库正文在目标可被匿名获取。实际 HTTP 原始文件和 Git 协议均复现；无需利用不合理配置、猜测未来变化或绕过网络故障控制。

### RB-INTERRUPT-003：Manager 被杀后源持续停服，备份仍显示执行中

- 位置：`backend/services/task_manager.py:16` 将整条备份放在进程内 daemon 线程；`backend/services/backup_consistency.py:181` 停止源，`:238` 的 `finally` 才负责重启源和释放锁。备份的终态及告警依赖该调用返回，API 启动未接续中断备份。冻结版本与当前两个因果文件摘要相同。
