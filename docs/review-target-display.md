# 审查接入目标的主备与完整路径

“接入审查仓库”抽屉原先使用独立接口，只展示实例名称；仓库搜索也只返回 Gitea 的 `full_name`。增强版层级群组使用内部兼容组织名，因而页面出现 `g_…/test_repo`，无法直接辨认业务群组。

实例接口现在补充已登记的主备角色及访问地址，自动接入抽屉与手动新增入口复用同一个实例选择器。候选项、选中摘要和本次接入目标显示角色、名称、地址；接入运行中仍禁止切换实例。

仓库搜索同时返回完整群组路径 `full_path`，候选、已选项和本次接入结果优先显示该路径。普通 Gitea 未提供该字段时沿用原名称。仓库编号、实例编号及提交用的 `name` 保持原值，不将展示路径代入现有权限或身份核验。
