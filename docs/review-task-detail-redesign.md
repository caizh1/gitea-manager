# 审查任务详情改版

目标用户是查看 AI 审查进度和处理待确认任务的仓库维护者。原页面将计划全文与单元表格置于进度之前，代表性样本中首屏无法看到执行日志。

改版把阶段、当前动作、耗时、剩余预算、模型与工具调用放在顶部；计划以一行摘要连接到“计划与依据”页签。正文、源码关系、边界及预算说明按需展开，原有信息保留。待确认、预算暂停和未完成任务直接进入计划页，避免隐藏必要操作；完成任务默认展示结果。日志、问题台账、覆盖信息和管理员诊断沿用原有数据与权限约束。

支持原生日志任务、历史任务和无计划数据的预检状态。数据来源与审查协议未修改。图标保持正常文档流，不使用绝对定位。

验收样本为固定的 7 单元、14 项关系任务及 6 种状态；1600、1280、1024、768、390 宽度均无横向溢出。运行任务在桌面首屏可直接看到当前动作和多条日志。计划确认与预算追加保留原来的摘要和 CSRF 校验协议。自动检查覆盖的是隔离界面行为，不代表生产模型效果或人工节省 80% 已达成。

设计稿、实际截图及提示词位于 `docs/design/review-task-detail-*`；视觉对照和检查过程见根目录 `design-qa.md`。回归入口是 `scripts/test_review_task_detail_ui.cjs`、`scripts/test_review_cost_table_ui.cjs`、`scripts/test_review_failure_checks_ui.cjs` 与 `scripts/test_review_diagnostics.cjs`。
