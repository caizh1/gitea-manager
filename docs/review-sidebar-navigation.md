# AI 审查二级导航

按已选第二版方案，将仓库管理、经验数据集、模型与设置三个入口移到左侧 AI Code Review 分组，保留审查工作区，移除内容区重复入口。分组位于提交门禁之后、仓库策略中心之前。

沿用已有路由和权限：模型与设置仅平台管理员可见，路由仍校验平台权限；整个分组遵循审查功能授权。侧栏和面包屑返回共用筛选参数保留逻辑，离开任务详情只保留最近任务标识，不在管理页打开详情。

图标使用正常文档流与弹性布局，展开箭头使用静态定位。窄屏自动收起侧栏；补充 Element Plus 竖向折叠菜单的点击展开，以便不依赖鼠标悬停。

## 升级

完整离线包使用固定 Linux amd64 镜像标签 `review-sidebar-20261015-r1`。前后端根据当前工作区构建；执行器沿用前次固定版本。将 `gitea-manager.tar.gz`、`gitea-manager.tar.gz.sha256` 和 `upgrade.sh` 放在同一目录，在部署机执行 `bash upgrade.sh`；存在多个实例时用 `--container` 指定已有后端容器。升级脚本负责校验、快照、切换、健康核对和失败回退。
