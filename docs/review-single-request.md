# 默认单次 PR 审查

新任务默认一次审查完整 PR，硬性上限为新增与删除合计 1200 行，跨文件累计。例如新增 1000 行、删除 200 行合计 1200 行；新增 701 行、删除 500 行合计 1201 行，会在模型调用前拒绝，不能按净增 201 行放行。上下文行不计入变更行数，但计入模型输入额度。

主审会同时看到全部变更与已解析关系所需的固定版本上下文。P0/P1 候选汇总后一次独立反证，逐项返回结论。历史意见的生命周期核对仍按既有规则运行，不能把“一次主审”理解为任何任务永远只发一个模型请求。

默认输入目标 65,536 Token，输出额度 32,768 Token；实际输入还受模型窗口及安全余量限制。合计 1200 行以内不保证一定装得下：完整源码和保护上下文超过额度时明确停止。合计超过 1200 行时在调用模型前拒绝，不截断代码、不自动分批；反证超额或输出截断也不自动拆分。

JSON、位置、证据范围、候选完整覆盖和完成状态仍严格校验。明确的位置错误可纠正一次，不能删掉意见、改写正文或降低级别来通过校验。

分批实现保留，配置字段 `batch_splitting_enabled` 默认 false，当前页面不增加启用入口。以后明确需要时可通过管理配置显式启用。新任务使用流程版本 6，已存在的任务保留原流程与计划；第五版未生成计划的任务也继续其净增 1000 行规则；切换模式只影响新任务，不静默重写运行中的任务。
