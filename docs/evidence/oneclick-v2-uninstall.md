# 首次安装失败卸载增量验收

新增两套安装包对应的 `uninstall.sh`；先输入 `UNINSTALL`，再完整输入含实例编号的 `DELETE ...`。取消任何一次确认不删除实例资源。删除范围为当前安装身份及 Compose 项目标签匹配的容器、已知数据卷、网络、安装状态和凭据；保留 Docker、镜像、离线依赖及不含凭据的卸载诊断。

- 7 项卸载单测及 11 项安装回归通过；Shell 语法检查通过；前端构建通过。
