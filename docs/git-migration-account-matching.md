# 迁移前人员匹配与确认

本功能供平台迁移管理员使用，已随 GitLab／Gitea 迁移功能合入主线。它在资料盘点与正式迁移之间增加独立的人员匹配确认页面。源端与目标端的用户名、编号和邮箱不需要完全相同。同一页面支持完整映射和快速保留来源身份两条路径，切换路径不会清空已确认结果。

## 操作流程

1. 完成资料盘点，选择目标实例及已有接收群组，点击“自动匹配并确认人员”。
2. 后台完整分页读取两端账号，不在浏览器请求中执行长时间扫描。名单与确认状态保存到 Manager 数据库，离开页面后仍可继续。
3. 在“自动匹配”标签页检查来源身份、目标账号和匹配依据。可以逐项改选，也可以使用该标签页内的“全部确认”按钮。
4. “确认全部自动匹配”只覆盖完整名单内尚未确认、没有被人工改选的唯一匹配项，不受当前搜索、分页或可见行限制。其数字是完整待确认自动匹配数。
5. 在名单中逐人勾选、全选本页或选择全部筛选结果，再点击“确认选中人员”。其数字是本次勾选数，可以跨页；切换筛选或搜索条件会清空勾选，名单修订变化也会清空旧选择。所选人员必须都已确定有效目标账号，存在未解决项时整批拒绝，不静默跳过。两种批量确认都在后台重新核验。
6. 对剩余歧义和未匹配人员，可逐项选择账号，也可点击“剩余人员保留来源身份”。影响预览区分可保留人数和权限例外，勾选了解影响后才执行。已确认映射及人工改选项不会被覆盖。
7. 所有人员均有有效、已确认的处理方式后才能继续。进度由已映射和保留来源身份两类组成；权限例外没有解决时仍不满足百分之百，前后端同时阻断，不能用空映射或旧用户名名单绕过。
8. 继续后仍需确认所有来源项目及依赖已经停止写入。人员全部确认不代表资料盘点、目标权限和其他迁移门槛自动通过。

## 自动匹配边界

- 只处理本次盘点实际需要的负责人、当前评审人及规则主体，不要求两端全部用户完全一致，也不为纯历史作者创建账号。
- 优先使用完整邮箱或用户名的精确匹配；只做首尾空白及大小写统一，不删除点号、邮箱加号或域名。
- 用户名与邮箱指向不同账号、重复邮箱、多个来源人员指向同一目标、只有姓名相同等情况保留为人工处理。
- 单个来源人员只能选择一个目标账号。团队、权限角色和可信 CI 回执账号必须由管理员明确指定；团队或角色可选择多个目标账号。
- 目标必须为可用账号，并具备所需的接收群组有效权限。结合有效授权及原生分单元权限判断，不能只凭总体角色或姓名猜测权限。
- 迁移程序不创建业务账号，不修改成员权限，不复制密码。目标确实缺少账号时，应先在目标端准备账号及权限，再刷新名单。

## 保留来源身份的实际效果

普通负责人和非正式评审请求可以保留为未绑定来源身份。目标事项的原始正文末尾追加来源人员说明，包含原角色、姓名、账号、来源实例编号和来源用户编号，且明确不会产生对应的目标待办、通知或权限。原始正文前缀、历史作者、Git 提交及邮箱均不改写。不同来源不会仅凭同名归并。

分支保护、标签保护、正式评审要求、团队角色及可信 CI 主体必须指定有效账号；同一人员同时承担这些职责时，保守地列为权限例外，不允许整项转为未绑定身份。有效授权同时核对原生权限与增强版仓库继承权限；审批名单要求评审读取权限，写入名单要求代码写入权限。

刷新后保留身份未变的两类确认；在“保留来源身份”中重新选择目标账号会撤销该项确认，重新确认后恢复为账号映射。执行计划保存固定的映射草稿编号、修订和来源身份清单，后续编辑草稿不会改写历史执行计划。

## 确认与变更保护

选择和确认是两个独立动作。修改已经确认的目标后，该项立即撤销确认，整体进度回退；重新确认后才能继续。即使进度接近百分之百，仍有未确认项时也不会四舍五入显示为百分之百。

后台批量确认会重新读取两端账号并核对原建议，避免把确认期间变化的身份当作旧建议批准。单项确认和正式提交也会再次核对目标稳定编号、登录名、账号状态、邮箱及有效权限。刷新时，身份与权限仍满足要求的既有确认可以保留；变更项需要重新检查。草稿有修订编号，过期标签页的更新不会覆盖较新的确认。

页面支持按状态与关键词筛选、服务端分页、直接搜索目标账号、保存草稿以及后台操作状态。新接口继承平台管理员与 CSRF 门禁，不向普通组织用户开放账号目录。

## 质量与验收口径

人工基线为逐个查询来源身份、查找目标账号、输入映射并核对权限。目标是在高匹配率的固定名单中显著减少重复输入，并将歧义和缺失集中处理；不以姓名猜测换取表面覆盖率。

固定基准包含七百五十人，并新增两千人、四个有效权限例外的范围校验。真实平台夹具覆盖跨页批量确认、筛选后排除、快速保留、正式和非正式评审区分、确认撤销、过期修订、直接 API 绕过、继承权限及迁移后逐项回读。入口为 `scripts/git-migration-retention-acceptance.py`。最终结果和样本分母以本轮验收报告为准。尚无真实公司项目的人工计时对照，不宣称整体人工工作已减少百分之八十。
