# 策略配置表单对齐 Gitea：验收报告

日期：2026-09-12。对象：熟悉 Gitea 分支保护设置的共享管理员。基准版本：Gitea 1.26.4。

交付使用本轮已验证的冻结源码及镜像。冻结后发现工作区 `backend/ai_review/common.py`、`backend/ai_review/assets/install.py` 等其他任务仍在修改；这些后续变更保留在工作区，没有临时混入本包。本报告仅验收策略表单及其回归范围。

## 交付范围和结果

实现模板内五组单列配置：表达式 → 推送 → 强制推送 → 合并请求批准 → 合并请求合并。保留多规则折叠，取消内部按数据类型拆分的折叠。推送、强推和合并以单选映射原有布尔字段；名单紧邻对应限制。沿用 Vue、Element Plus、模板管理、批量应用与执行记录。

用户和团队改为搜索多选。新增登录保护的 `GET /api/repository-policies/users`、`GET /api/repository-policies/teams`，支持实例、关键词、页码；团队必须指定组织。每页 20 项、500 毫秒防抖、过期响应隔离，复用数据库共享的每实例每秒两次限流。保存仍使用原名称数组和 `team_org`，没有数据库迁移。

规则正文以 [Gitea 原生模板](https://github.com/go-gitea/gitea/blob/v1.26.4/templates/repo/settings/protected_branch.tmpl)和同版本中文翻译为参考。审批阻塞等少数原生翻译改成较明确的中文，额外显示 Manager 的规则优先级与组织；没有复制 Gitea 外层导航或替换 Manager 的整体样式。

## 人工基线、质量指标与样本

人工基线：同一管理员在修改前表单配置相同名单或状态检查。输入为现有 `研发保护标准` 模板和已知用户名；候选查询使用本机独立 Gitea。固定样本要求 30 个 API 字段和组织无损往返、零误报成功、零意外修改其他规则。错误路径须保留已选值，跨组织不得同名自动替换。

真实样本使用 `policy-qa`、`policy-qa-other` 两个组织，原有开发及审查用户，另建立 21 个独立分页用户和 21 个分页团队。团队没有被授予业务仓库权限。测试模板 14 包含 `main` 和 `release/ui-*`；空白模板 15 为 `feature/form-*`。批次 16 验证原样保存，批次 17 应用到 `policy-qa/batch-30`、`policy-qa/batch-29`。

## 固定任务操作数和耗时

每个任务独立重新打开相同模板。一次点击或填写计一次操作；排除两版共有的登录、打开编辑器与最终保存。没有计入真人阅读和寻找控件耗时，下面时间是浏览器自动化操作的墙钟时间，包含新表单的真实候选请求等待。

| 任务 | 原表单操作数 | 新表单操作数 | 原表单毫秒 | 新表单毫秒 |
|---|---:|---:|---:|---:|
| 推送白名单 | 4 | 3 | 858 | 1122 |
| 强制推送白名单 | 5 | 4 | 1112 | 1440 |
| 批准白名单 | 2 | 2 | 315 | 839 |
| 合并白名单 | 3 | 3 | 582 | 1177 |
| 状态检查 | 2 | 1 | 301 | 11 |
| 合计 | 16 | 13 | 3168 | 4589 |

此固定任务减少 3 次操作，即 18.75%；自动化耗时增加 1421 毫秒。不得由此宣称人工效率提高 80%，也不能把上一期批量功能的数据归因于本次表单调整。真人熟悉度、阅读时间和较大名单实际选取时间尚未实测。

## 主要修改模块

- `RepositoryPolicies.vue`：嵌入单规则编辑器，稳定规则组件身份，保留外层模板和批量流程。
- `PolicyRuleEditor.vue`、`PolicyAllowlist.vue`：五组配置、相关名单、依赖禁用和组织更换确认。
- `PolicyIdentitySelect.vue`、`policyForm.js`：远程多选、分页、防抖、取消与旧响应隔离、数据无损转换。
- `policy_routes.py`、`policy_gitea.py`：只读候选路由和 Gitea 搜索适配，复用既有鉴权和限流。
- 两组新增测试、使用说明、README、中文证据与部署包。

```bash
node --test frontend/tests/policyForm.test.mjs
npm --prefix frontend run build
docker run --rm --network none -v "$PWD/backend:/app:ro" -w /app gitea-policy-local-backend python -m unittest discover -s tests -v
```
