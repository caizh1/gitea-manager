# 迁移目标实例的主备识别

SVN 与 Git 迁移的目标选择原先只显示登记名称。自动生成的容器名称不能表达主备，同名实例尤其难以确认。

现在统一显示“主服务器／备服务器 · 登记名称 · 访问地址”。下拉候选分行显示角色、名称和地址，支持按这些内容搜索；选中后保留可换行的完整摘要。SVN 计划预览、工作台、预检和执行详情使用同一显示规则。缺失或未知角色显示“角色未设置”，不从名称推断角色。

本次只更改目标识别信息，继续使用原实例编号选择目标、查询群组及提交计划；保留归档实例过滤，不自动改变主备角色、权限或迁移范围。

验收对象为平台管理员。人工基线是在目标名称无法区分时返回服务器管理核对角色和地址；固定样本使用两个相同容器式名称、不同角色和地址的实例，要求页面直接提供全部核对信息。没有实测真实用户操作耗时或人工介入比例，不宣称达到减少人工 80%。
