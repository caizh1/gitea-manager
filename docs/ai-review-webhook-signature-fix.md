# AI Review Webhook 验签修复与升级验收

日期：2026-10-27。升级版本：`manager-ai-webhook-upgrade-20261027-r1`。

## 问题与修复

原有全局实例互斥检查在判断接口前调用 `request.get_json()`。该调用读取原始输入流并缓存字节，后续 AI Review 直接读取已耗尽的输入流，导致两端密钥相同、合法签名仍被拒绝，自动接入显示投递检查失败。

- 实例互斥检查只处理服务器修改、删除、备份创建、恢复创建和恢复重试五类接口，仅对确实需要的请求解析 JSON。
- Webhook 使用缓存中的原始字节验签，保留空白、换行及中文字符，不重新序列化 JSON。
- 未缓存的请求最多读取 1 MiB 加一个字节；超限返回 413，错误签名仍返回 403。不会关闭签名校验或放宽仓库身份检查。
