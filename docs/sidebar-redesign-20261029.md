# 侧栏方案一：实现与视觉验收

日期：2026-10-29。范围：`frontend/src/App.vue` 的导航外观、折叠按钮和底部账号入口。

## 目标与边界

使用者为平台和组织管理员。原界面品牌区居中且偏高，折叠按钮另占一整行；优化为紧凑品牌行，提升菜单辨识度。保留既有权限判断、路由、菜单顺序及 240/64 像素宽度，不迁入遗留迁移分支，不改变后端和业务执行行为。

输入为用户选定的第一张设计图。验收指标为：品牌区及按钮不重叠，图标不用绝对定位；父子菜单选中层级清楚；展开、折叠、子菜单、账号入口可用；四种宽度无侧栏溢出；有限权限菜单不新增越权入口。固定样本为平台管理员、仅有仪表盘和服务器权限的组织管理员、超长账号名、迁移子菜单和审查子菜单。

本轮为界面外观改进，没有人工耗时对照或模型效果验收，不宣称已减少 80% 人工精力。

- 设计原图：`docs/evidence/sidebar-20261029/reference.png`，850 × 1850 像素。

## 比较过程

首轮发现 P2 菜单密度偏松：品牌区 84 像素、主行 44 像素加外边距、底部 69 像素；小高度视口比设计更早出现滚动。原证据为 `sidebar-before-density-fix.png`。修正为品牌区 76 像素、主行 40 像素、子行 34 像素、底部 61 像素，重拍并完成并排复核。

后台视口连续变化时，曾取到菜单高度过渡中的像素帧，不能作为最终效果。最终证据以固定内嵌视口的新页面拍摄，并核对三个迁移子项均完整呈现。
