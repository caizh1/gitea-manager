# AI 审查工作区与统计

## 范围与口径

面向平台管理员和组织审查人员。人工基线是逐页查阅任务、分别记录状态与问题、核对反馈；新版由后端在权限过滤后的完整数据集上聚合，默认近 30 个浏览器时区自然日。支持近 7 天、近 90 天和最多 366 天自定义范围。

成功与失败按所选期间创建任务的当前状态计算，取消、过期、进行中、发布待核对单列。成功率只使用成功与失败作分母，执行成功不代表没有代码问题。P0/P1 只读取结构化等级，稳定台账编号去重并按来源任务日期归属；未可靠关联的旧意见另计，不猜测文字报告。

已接受只计已有人工有效反馈，按意见身份合并；冲突、撤销、误报和停用单列。无兼容反馈链路时显示暂无数据，不提供整体接受率。本次没有新增反馈入口或连接当前审查与旧反馈协议。

接口为只读 `GET /api/ai-review/statistics`，参数 `start`、`end`、`timezone`、`repository`。任务列表接受同样日期参数。统计采用 SQLite 一致读事务，先按仓库与历史任务归属过滤；归档仓库遵循既有权限，仅平台管理员可查。新增查询索引，数据库版本 16。

## 操作

首页显示五项指标和两组图表（每日任务结果、人工反馈分布），图表附精确数值。仓库、数据集、模型设置迁移到独立子页面，快速接入位于仓库页面。

点击任务后，左侧约 320 像素列表可直接切换，右侧展示报告或实时过程；左上角返回完整列表。日期、状态、页码、最近选择保存在链接中，兼容旧 task 参数并支持前进后退。同页返回恢复滚动位置。内容宽度不足 960 像素时只展示详情。打开详情自动收起图表，已完成任务默认收起执行摘要与诊断。

统计每 30 秒更新，任务列表每 5 秒更新，详情沿用现有轮询。切换统计范围会取消旧请求；组织切换通过现有页面生命周期隔离，卸载取消请求并丢弃过期响应。

## 验证记录

- 后端相关回归 130 项通过；补齐归档与部分归档样本后，统计专项 12 项通过。
- 固定样本覆盖全任务状态、日期边界、夏令时、超过一页的聚合、重复问题、来源时间与导入时间差异、部分归档、反馈别名与冲突撤销、缺失结果和空数据。要求样本预期逐项完全相等，不设容许误差。
- 真实认证接口验证匿名拒绝、组织隔离、平台权限、历史归属代次及归档权限。首次归档样本错误地假设原组织仍可查看；核对既有权限实现后改为明确验证组织拒绝、平台保留，并非放宽访问权限。
- 前端生产构建通过。真实浏览器已采集旧版对照及新版概览、并排详情、窄屏、仓库子页截图；验证直接切换、报告默认页、发布核对入口、返回、前进后退、深链接刷新。
- 独立预览使用 64 条固定任务：成功 24、失败 8、取消/过期/运行/待核对各 8；台账 P0 为 4、P1 为 12，接受数据未知。未连接用户 Gitea 或模型。
