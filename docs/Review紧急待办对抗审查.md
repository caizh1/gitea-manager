## P0/P1 BLOCKERS

无。

## 审查范围与反证

- **任务状态与并发**：待办来自 `publish_unknown`，领取规则保留同 PR 阻塞。分别聚合未知与排队任务，排除多待办连接放大计数。多个阻塞项必须全部解决后才可领取，已用数据库测试反证“解一个就全部放行”。
- **重复发布**：进入面板仅排入只读核对；Worker 调用现有正式 Review 的归属、固定 SHA、冻结正文、评论集合和位置验证。无新增发布 POST、草稿续发或删除路径。真实回执丢失场景核对前后 Review 数不增加。
- **管理员确认**：复用 PR 发布锁，在锁内重新读取任务；检查正式 Review 和机器人残留草稿后才标记未发布。同一任务已被处理时返回当前状态。确认和核对不能绕过身份、CSRF 或配置锁。
- **配置与接入**：只读核对请求持共享配置锁，配置修改和自动接入继续持同名独占锁。核对请求彼此并发，数据库短事务原子合并；未移除发布锁。专门测试共享读与独占写互斥。
- **代次与通知**：新增触发器在旧版本进入／退出待核对状态时更新对应 PR 的通知序列。现有进度同步仍在联网后回读当前代次，通知不改变任务的执行代次或模型结果。
- **断线和重启**：核对失败保留未知状态；记录开始和结束时间、可见错误。核对期间中断后由到期扫描再次执行只读查询，不把中断视为未发布。Worker 无心跳不作成功推断。
- **数据升级**：幂等新增字段和索引／触发器，历史核心字段不重写。测试移除新字段后按旧库重建迁移，重复启动并核对历史字段保持。
- **前端生命周期**：全局状态与页面复用；5 秒读取超时；失败保留最后状态。会话代次令旧请求不能在退出／重登后写入新状态，已验证迟到响应和计时器隔离。
- **权限和内容**：接口沿用登录、同源和专用 CSRF；所有筛选值验证后参数化查询。页面使用 Vue 文本插值，PR 组件使用文本节点并核验可信机器人、仓库、PR 和字段结构。待办查询不返回令牌、快照源码或模型完整输出。
- **资源与部署**：不新增依赖、进程停止接口、Docker／SSH 权限或凭据挂载；完整离线流程沿用既有固定镜像、秘密排除和升级保护。

以上候选风险均结合现有保护、可达路径和回归／真实实例结果进行反证，未发现达到 P0/P1 的成立问题。

## UNVERIFIED RISKS

- 实际内网部署的网络、原有历史规模和用户操作尚未现场验收；不能由本机实例推断其已升级成功。
- 正式 Review 请求确实结束仍需管理员核对，远端读取不能证明一个仍在处理的网络请求未来一定不会落地；因此没有自动“确认未发布”。
- 全流程人力节省和真实部署模型的缺陷识别质量未测量；固定发现基准仅衡量导航操作。

上述验收边界不构成当前方案的 P0/P1 阻塞。
