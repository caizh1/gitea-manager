## 本轮修复与仍开放的问题

- 已修复：普通提交事件晚到导致新审批被误清除；原生时间线隐藏评论造成分页漏读；读取审批后、资格检查期间撤回却沿用旧批准。首次错误合并证据与修复回归均保留，不能删除失败。
- 已修复：跨实例策略 ID 复用时展示缓存范围不足；隐藏/关闭页面遗留请求超时计时器。
- 已修复：维护期间展示服务正确拒绝业务请求（503），升级健康检查却要求 404，导致误报启动失败。实际复验 `193703-4a5ac8cc` 已记录失败及自动回退成功；修复为核验维护响应及实际路由表，解除维护后另检验 404。
- 已修复：升级入口遗漏新增 `approval-view` 启动及回退服务列表。静态发现的路径是新版本健康检查要求该服务，但入口未启动它；实际离线升级与中断回退由包外报告验证。未把源码推导写成已发生的生产故障。
- 未修复：APR-RACE-001 最终核验后撤回或移组；APR-CUTOVER-006 导出后、激活前新建 PR 未按预期豁免。后者可能额外阻断，不是本次已证明的错误放行。
- 未完成：500/1,000 用户容量、双 24 小时、全部安装中断和非协作修改窗口、运维漂移、审计保留及资源上限、全部现场代理/数据库环境、现场正常业务与人工精力减少 80%。

开发机 Docker 客户端间歇连接失败已有独立空容器复现；切换配套客户端并未消除。最终页面用例之前的初始化失败单独记录，不记为页面功能失败或通过。后续验收驱动器可使用直接 Unix socket 传输，保留退出码和二进制输出，不自动重放写请求；这不代表 Docker 根因已修复，也不修改生产连接方式。
