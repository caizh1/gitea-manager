# 账号安全改密与导航图标审查

VERDICT: PASS

P0/P1 BLOCKERS:

无。审查范围包括本人改密接口、认证源公开字段、初始密码门禁、当前及其他会话、CSRF、两个 worker 的并发写入、前端请求生命周期、目录账号隔离、权限缺失状态、菜单折叠及离线依赖。

对候选阻塞问题逐一反证：

- 并发改密覆盖：两个请求可同时通过旧密码校验；实现通过旧密码哈希和认证版本条件更新，只允许一个提交。双请求同步屏障回归验证一个成功、一个冲突，只有一条改密审计与一个有效新会话。
- 旧会话继续有效：认证版本更新与撤销旧会话在同一事务提交；后续会话加载比较数据库认证版本。复制旧 Cookie 和第二浏览器均已被拒绝，当前会话使用新的令牌及 CSRF。
- 目录管理员误改本地密码：后端检查账号来源，前端按明确的 `auth_source` 字段展示。与本地管理员同名、已获平台管理员权限的目录账号也不能改本地密码。
- CSRF 或匿名绕过：沿用统一账号端点登记及同源校验；缺失/旧 CSRF、跨站请求和匿名请求均被拒绝。
- 页面放宽业务授权：新增账号路由仅用于本人信息及改密，后端业务接口权限清单未放宽；未配置本机 IP、未分配组织的目录账号仍受原业务门禁限制。
- 密码和状态泄漏：密码只存在表单内存；组件卸载取消请求并清空输入，审计和响应无密码或哈希。保存成功取消旧会话在途请求并立即应用新 CSRF，避免旧轮询覆盖。
- 更新故障与未知结果：密码、兼容存储与会话撤销同事务；请求有 30 秒超时且不自动重试，网络失败提示结果待确认。提交后连接中断可能需要用新密码重新登录，不能保证原 HTTP 请求回执一定到达。
- 菜单图标布局：统一矢量轮廓，固定图标盒子与正常文档流；390 至 1536 宽度以及折叠展开均检查。未使用绝对定位承载新图标。

UNVERIFIED RISKS:

- 真实生产宿主机、用户现有部署升级及真实 LDAP / AD 服务不在本次隔离验收范围。
- 未采集真实管理员与运维的人工操作对照，不能宣称已实测节省 80% 精力。
- 工作区原有备份恢复修改被保留；此次审查聚焦账号、会话、导航及其调用链，不替代备份恢复专项验收。

NON-BLOCKING FINDINGS:

- 初版浏览器检查发现菜单折叠时图标短暂裁切，以及快速离开保存中表单再返回时路由过渡导致空白内容。已修复并保留相应回归场景，最终以复验结果为准。
- 扩展回归发现旧测试期望数据库版本 13，而现行 Review 存储版本为 17。使用修改前的认证代码复现同样失败后，只更新版本断言，原权限字段、历史记录、配置密文和幂等检查保留；85 项回归已通过。
- 现有构建仍提示大体积入口分包和第三方纯函数注释警告，构建成功；本次未扩大为整体前端拆包工作。

详细验收与交付证据见 `account-security-acceptance.md`。
