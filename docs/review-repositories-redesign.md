# 审查仓库管理改版

日期：2026-10-27。

## 目标与支持范围

目标用户是维护已接入仓库的平台管理员，以及管理授权范围内仓库审查开关的组织管理员。原页面将快速接入区域与仓库管理表格上下排列，每行并列多个操作，已配置条目缺少移除入口。本次以用户确认的设计图为参考，将日常仓库管理放在首屏，接入表单移入右侧抽屉。

人工基线为逐条查找仓库、辨认实例和事件通知状态、打开配置，以及手工核对并移除本接入通知。改版提供名称搜索、实例和状态筛选、分页、行内配置和更多菜单。数量来自实际可见配置，不展示虚构指标；没有隐私信息的历史记录显示“审查仓库”，不猜测是否私有。窄屏改用正常文档流中的仓库行，保留可见操作入口。

验收标准：现有配置和人工审查入口可达；接入不占用主表格空间；搜索和筛选结果正确；正常移除只处理该接入通知并保留仓库与历史；异常结果不得显示成功；组织管理员看不到平台接入与移除入口；390、768 和 1536 像素布局不发生整页横向溢出或按钮重叠。本次没有测量真实管理员耗时、误操作率或人工介入比例，不能宣称达到减少人工精力 80% 的目标。

## 使用方式

- 点击右上角“接入仓库”进入抽屉，选择实例、仓库并检查启用。已有专用机器人时，抽屉保留手动配置入口。
- 已配置仓库在主表格展示。“配置”继续使用已有权限和版本校验；“更多”保留审查、事件通知、下载进度组件，并新增“移除接入”。
- 普通列表隐藏已完成移除的记录；“已移除”筛选可查看留存记录。原组织失效的归档记录与主动移除区分处理。
- 平台管理员才能移除。二次确认会明确保留 Gitea 仓库、历史审查、机器人账号和共享进度组件。

## 移除行为与失败恢复

移除请求为 `DELETE /api/ai-review/repositories/<编号>`，提交当前配置版本，同时经过统一平台管理员权限、登录、CSRF 及自动接入互斥保护。

1. 短事务中核对版本以及运行、取消、发布待核对状态和仍有效的旧执行租约；不满足条件时阻止移除。
2. 将接入停止并封存，终止排队和等待预算的旧任务，撤销执行授权。历史任务、意见和样本仍关联原内部编号。迟到通知返回忽略，不再写入新任务。
3. 在事务外核对目标实例、仓库稳定编号和名称，以及已记录 Webhook 编号和完整回调地址，只删除完全匹配的通知；删除后回读其是否不存在。
4. 删除响应丢失时只回读结果；确认已不存在才成功，不重复删除。连接失败、身份变化或通知被修改时保留停止接入状态，展示失败原因和“重试移除”。
5. 成功后清除本条配置中的机器人密文和签名密文；不撤销可能被其他仓库共享的真实机器人令牌。再次接入使用新内部编号，旧历史不迁移。

运行或发布待核对任务需要先在审查工作区处理；移除流程不会替用户确认未知发布结果。历史配置若没有可核对的通知编号和回调记录，拒绝猜测删除，需管理员核对原通知记录。未测试生产 Gitea、物理 Linux 宿主机或长期大规模使用；本次不改变模型审查能力。
