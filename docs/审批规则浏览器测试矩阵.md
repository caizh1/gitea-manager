# 审批规则真实浏览器测试矩阵

2026-09-13 用户追加要求：后台自动化与接口矩阵不足以模拟实际使用，必须直接操作浏览器。本文是独立验收层，浏览器未操作的用例不能引用后台通过结果代替。

初始被测版本：已交付 `approval-internal-20260913-r2` 固定镜像。只创建唯一标记的官方 Gitea 1.26.4 和 Manager 隔离实例，预置组织、成员、原生保护及存量 PR。初始化造数、故障注入和 Git 引用核对可使用运维工具；以下规则编辑、批准、撤回、评论、合并等用户动作必须通过真实页面完成。多用户同时发压与双 24 小时仍按先前安排后置。

每项记录页面入口、实际身份、点击/输入步骤、可见结果、截图或页面快照、必要的 Git 引用/业务记录核对，以及首次失败和修复复测。关闭原页面不等于故障；窗口过期或测试环境未就绪应记录未完成，不归为产品通过。
