# PR-Agent

固定使用 0.49.0，源提交为 `4ae117c4af71ec92e361f8dee1124439f8a7b4a3`，采用该提交自带的 MIT 许可证。原始许可证随 Python wheel 交付，源码归档及依赖摘要保存在离线资源目录和依赖清单中。

源码来源为 https://github.com/the-pr-agent/pr-agent 。运行时采用独立 Python 3.12，固定依赖见 `pr-agent-requirements.txt`。旧版 Manager 执行器经 Manager 网关调用模型。原生 Gitea 服务使用接入通道配置的模型凭据直接访问模型服务。
